# 151 — Product Analytics

## Objective
Measure how customers and providers use the platform.

## Customer Funnel
```text
App Open
 → Search/Service Selection
 → Quote
 → Checkout
 → Booking
 → Completion
```

## Key Metrics
- activation
- conversion
- abandonment
- repeat usage
- retention
- cancellation
- service adoption

## Segmentation
Possible dimensions:
- city
- service
- customer cohort
- acquisition source
- device/platform

Avoid exposing personal data unnecessarily.

## Definition of Done
Product teams can identify conversion bottlenecks and usage trends.
