# 183 — Security Testing & Hardening

## Objective
Reduce application, infrastructure and account security risk.

## Areas
- authentication
- authorization
- API abuse
- injection
- file uploads
- secrets
- session security
- rate limiting
- dependency vulnerabilities
- infrastructure permissions

## Testing
Perform:
- SAST
- dependency scanning
- API security tests
- authorization tests
- targeted penetration testing

## Critical Rule
Never rely on client-side permissions for security.

## Definition of Done
Critical security controls are automated where practical and independently reviewed for high-risk areas.
