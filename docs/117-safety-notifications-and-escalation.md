# 117 — Safety Notifications & Escalation

## Objective
Ensure important safety events reach the correct responders quickly.

## Priority
Safety notifications require separate priority handling from marketing/product notifications.

## Channels
Depending on event and local policy:
- in-app
- push
- SMS
- phone/call workflow
- operations dashboard

## Escalation
```text
Event
 ↓
Primary Responder
 ↓ timeout
Secondary Responder
 ↓ timeout
Escalation
```

## Delivery
Critical notifications should be tracked:
```text
created
sent
delivered
acknowledged
```

## Definition of Done
Critical safety events have measurable notification delivery and escalation paths.
