# 137 — Admin User & Driver Management

## Objective
Give authorized staff a complete driver/account operational view.

## Driver View
Show:
- profile
- verification state
- vehicles
- service eligibility
- current availability
- current job
- earnings summary
- ratings
- cancellations
- incidents
- document status

## Actions
Depending on permissions:
- verify
- activate
- deactivate
- suspend
- restore
- request documents
- change service eligibility

## Safety
Sensitive information should be masked by default.

## Definition of Done
Driver operations can resolve common account and eligibility issues through controlled workflows.
