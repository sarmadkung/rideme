# 159 — Analytics Dashboards

## Objective
Create role-specific dashboards rather than one overloaded analytics screen.

## Dashboards
```text
Executive
Operations
Dispatch
Driver
Merchant
Finance
Product
Trust & Safety
```

## Executive
- revenue
- orders
- rides
- active users
- marketplace health
- contribution

## Operations
- active jobs
- unassigned jobs
- ETA
- SLA
- exceptions

## Design
Dashboards should show:
```text
KPI
trend
comparison
breakdown
actionable exception
```

## Definition of Done
Each dashboard answers a defined operational/business question.
