# 119 — Safety Operations Dashboard

## Objective
Give authorized operations staff a focused interface for urgent safety and trust work.

## Queues
```text
Critical Incidents
High Risk
SOS
Verification
Appeals
Fraud Review
Expired Documents
```

## Incident Detail
Show relevant:
- user
- driver
- vehicle
- trip/job
- timeline
- evidence
- risk indicators
- actions

## Actions
Depending on permissions:
- acknowledge
- assign
- contact
- restrict
- suspend
- resolve
- escalate

## Safety
Sensitive fields should be masked unless required.

All privileged actions are audited.

## Definition of Done
Authorized safety operators can investigate and resolve incidents without direct database access.
