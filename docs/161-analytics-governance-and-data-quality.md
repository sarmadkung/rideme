# 161 — Analytics Governance & Data Quality

## Objective
Keep analytics trustworthy as the platform grows.

## Governance
Maintain:
- event dictionary
- metric definitions
- ownership
- lineage
- data classifications
- retention rules

## Quality Checks
Examples:
```text
freshness
completeness
uniqueness
validity
referential integrity
```

## Metric Ownership
Each critical KPI has an accountable owner.

## Sensitive Data
Do not copy sensitive operational data into analytics without a defined purpose and access policy.

## Definition of Done
Teams can determine where a metric comes from and whether its data is trustworthy.
