# 138 — Admin Vehicle & Fleet Management

## Objective
Manage vehicles across ride, delivery and cargo services.

## Vehicle View
```text
vehicle
driver
type
capacity
documents
verification
services
status
```

## States
```text
PENDING
ACTIVE
INACTIVE
SUSPENDED
EXPIRED
REJECTED
```

## Fleet
Support:
- individual owner
- business fleet
- multiple vehicles per owner
- vehicle assignment

## Actions
- approve
- suspend
- change service capability
- update capacity
- verify documents

## Definition of Done
Operations can maintain accurate vehicle eligibility used by dispatch.
