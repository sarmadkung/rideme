# Business Model & Unit Economics

## Positioning

A marketplace and infrastructure layer for local transportation and logistics.

## Revenue Streams

### Passenger
- Platform commission
- Optional booking/service fee

### Parcel
- Delivery fee
- Platform margin

### Cargo
- Marketplace commission
- Optional loading/waiting fees

### Merchant Delivery
- Per-delivery fee
- Merchant subscription for advanced features

### Enterprise
- Contract pricing
- Monthly minimums
- Dedicated fleet/dispatch features

### API
- Per-job API fee
- Enterprise subscription

### Future
- Fleet management SaaS
- Insurance partnerships
- Vehicle/driver financing partnerships
- Working-capital products

## Pricing Principles

Never optimize only for commission percentage.

Optimize for:
- Driver retention
- Customer conversion
- Contribution margin
- Vehicle utilization
- Empty-km reduction

## Passenger Pricing

Base fare
+ distance
+ time/waiting
+ vehicle type
+ demand adjustment
+ applicable fees

## Parcel Pricing

Base
+ distance
+ weight
+ dimensions
+ urgency
+ waiting/loading if applicable

## Cargo Pricing

Base
+ distance
+ vehicle type
+ capacity
+ loading/unloading
+ waiting
+ scheduled/intercity requirements

## Fair Pricing

Show the customer:
- Estimated fare
- Fare range where appropriate
- Main price components
- Cancellation terms

Show the driver before acceptance:
- Gross earnings
- Estimated distance
- Estimated duration
- Estimated platform fee
- Estimated net earnings

## Driver Economics

Core KPI:

**Net driver earnings / online hour**

Also track:
- Revenue/km
- Empty km
- Jobs/hour
- Acceptance rate
- Completion rate
- Cancellation rate

## Unit Economics Template

For each job:

Gross Booking Value
- Driver payout
- Payment processing
- Incentives
- Insurance/risk reserve
- Support cost
- Maps/communications variable cost
= Contribution Margin

## Launch Rule

Do not subsidize jobs indefinitely.

Every launch zone should have a measurable path toward positive contribution margin.
