# 139 — Admin Merchant Management

## Objective
Manage merchant onboarding and operational health.

## Merchant View
Include:
- business profile
- stores
- catalog status
- orders
- fulfillment metrics
- settlements
- incidents
- support cases

## Actions
- approve
- suspend
- activate/deactivate store
- require document updates
- restrict service
- review disputes

## Definition of Done
Merchant operations can resolve onboarding and service issues without database intervention.
