# 156 — Operational KPIs & SLA

## Objective
Create measurable service-quality standards.

## Ride KPIs
- request-to-match time
- driver arrival time
- trip completion
- cancellation
- ETA accuracy

## Delivery KPIs
- pickup delay
- preparation delay
- on-time delivery
- failed delivery
- POD completion

## Support KPIs
- first response time
- resolution time
- reopen rate

## SLA
Every SLA should define:
```text
metric
target
scope
measurement window
exclusions
```

## Definition of Done
Operations dashboards use agreed KPI definitions rather than team-specific calculations.
