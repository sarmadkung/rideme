# 179 — React Native & React Testing

## Objective
Test customer, driver and admin applications.

## Component
Use component tests for:
- forms
- booking flows
- lists
- pricing display
- state transitions

## React Native
Test:
- permissions
- deep links
- location adapters
- background behavior through platform-specific test strategies
- offline/reconnect behavior

## Admin React
Test:
- filters
- tables
- permissions
- operational actions
- realtime updates

## Principle
Do not over-test framework internals. Test observable behavior.

## Definition of Done
Critical screens and shared components have stable automated coverage.
