## Product Thesis

> Any compatible vehicle can perform multiple kinds of jobs, and the platform continuously matches demand to the best vehicle while maximizing driver profitability and minimizing empty kilometers.

## Initial Wedge

Bike + Rickshaw + Car + Loader/Suzuki

Services:
- Ride
- Parcel
- Small cargo

## Long-Term Vision

Ride
→ Local delivery
→ B2B logistics
→ Merchant delivery
→ Return loads
→ Intercity
→ Freight
→ Logistics API

## Important

These documents are strategic starting points. Pricing, city selection, legal requirements, vehicle categories and unit economics must be validated through local field research before launch.
