## Realtime
Use WebSockets for new orders, order changes, driver arrival, pickup and delivery completion.

TanStack Query remains the server-state authority; realtime events update or invalidate relevant queries.

## Permissions
UI should hide unavailable actions, but backend APIs must always enforce permissions.

## Definition of Done
A merchant can operate daily fulfillment entirely from the React dashboard.
