# 182 — Mobile Performance & Battery

## Objective
Keep React Native applications responsive while preserving battery life.

## Areas
- startup
- navigation
- list rendering
- map rendering
- GPS
- realtime
- image loading
- memory

## Driver App
Particular attention to:
- background location
- tracking frequency
- reconnect behavior
- map/navigation
- long active sessions

## Native Modules
Use native implementations for platform-sensitive performance areas without duplicating business logic.

## Measurement
Track:
- startup time
- frame drops
- memory
- battery impact
- location update efficiency

## Definition of Done
Driver and customer applications remain usable during long sessions on realistic devices.
