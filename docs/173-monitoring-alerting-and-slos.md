# 173 — Monitoring, Alerting & SLOs

## Objective
Turn observability data into actionable operations.

## SLO Examples
```text
API availability
API latency
Realtime connection success
Job assignment latency
Notification delivery
```

## Alerts
Alert on user-impacting conditions rather than every low-level anomaly.

## Alert Levels
```text
CRITICAL
HIGH
WARNING
INFO
```

## Alert Requirements
Each critical alert should include:
- impact
- dashboard
- runbook
- escalation
- owner

## Definition of Done
Critical production failures generate actionable alerts with clear ownership.
