# 152 — Marketplace Analytics

## Objective
Measure supply/demand balance and marketplace health.

## Core Metrics
```text
requests
available drivers
acceptance rate
assignment rate
completion rate
cancellation rate
ETA
wait time
utilization
```

## Supply
Analyze:
- online hours
- active hours
- idle time
- jobs per driver
- earnings
- utilization

## Demand
Analyze:
- requests by zone/time
- unfulfilled requests
- peak periods
- service mix

## Definition of Done
Operations can identify where supply and demand are mismatched.
