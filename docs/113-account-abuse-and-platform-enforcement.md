# 113 — Account Abuse & Enforcement

## Objective
Handle abusive behavior consistently.

## Abuse Types
- harassment
- threats
- fake accounts
- spam
- fraud
- repeated no-shows
- malicious cancellation
- review manipulation
- platform exploitation

## Enforcement
```text
WARNING
LIMITED
TEMPORARY_SUSPENSION
REVIEW_REQUIRED
PERMANENT_BAN
```

## Scope
Enforcement may apply to:
- account
- driver
- vehicle
- merchant
- service
- payment method

## Appeals
Users should have an appropriate appeal/review process for serious actions.

## Audit
Every enforcement action records:
- actor/system
- reason
- policy/rule
- timestamp
- duration
- appeal status

## Definition of Done
Abuse can be addressed without irreversible manual database edits.
