# 114 — Incident Management

## Objective
Create a structured workflow for safety, operational and service incidents.

## Incident Types
```text
SAFETY
ACCIDENT
FRAUD
PACKAGE_DAMAGE
THEFT
HARASSMENT
SERVICE_FAILURE
SECURITY
```

## Severity
```text
P1_CRITICAL
P2_HIGH
P3_MEDIUM
P4_LOW
```

## Lifecycle
```text
OPEN
TRIAGED
INVESTIGATING
ACTION_REQUIRED
RESOLVED
CLOSED
```

## Evidence
Attach references to:
- trip/job
- messages
- POD
- payment records
- relevant location events
- support conversations

Avoid copying sensitive data unnecessarily.

## Definition of Done
Operations can investigate incidents with complete context and an auditable timeline.
